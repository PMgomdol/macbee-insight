## 2. 안건별 논의 포인트

### A. 등록 방식·속도 — 2인 승인을 누구에게 적용할지  ★가장 중요
**현상**: 시트 때는 맥비님이 붙여넣으면 끝. 지금은 한 건씩 폼 → AI 분석 대기 → 다른 운영진 승인 대기. 실제 등록의 대부분을 하는 맥비님에게 병목.
**제안**: 외부 방문자 제안만 2인 승인 유지. **운영진이 올린 자료는 바로 게시**, 다른 운영진은 자료 관리에서 사후 검수(숨김·복구로 되돌림).
**물어볼 것**
- 맥비님: 링크를 평소 어디에 어떻게 모으시나요? (톡방 / 북마크 / 시트) → 일괄 등록 방식 설계 근거
- 전원: 운영진이 올린 걸 사전 검수 없이 공개해도 되는가? 우려가 있다면 무엇인가?
**선택지**
1. 운영진 등록 즉시 게시 + 사후 검수 (추천)
2. 운영진 등록은 1인 승인만 (본인 외 1명)
3. 지금 그대로 2인
**결정되면**: 1번은 반나절 작업. 이어서 여러 URL 일괄 등록(관리 화면), 읽던 페이지에서 바로 등록(공유 시트/북마클릿) 순서로.
**부수 결정**: 제안자 본인이 자기 제안을 승인하는 것 허용할지 (지금은 허용됨 — 개인정보보호포털 건이 그 예)

### B. 오픈 시점·방식
**현상**: 검색엔진 노출 차단 중. 맥비님 제안 — 파일 등록만 확인되면 베타 오픈 후 이용자 의견 수집.
**정할 것**
- 베타 오픈 날짜 (드라이브 연결 테스트 완료 직후가 현실적 — 이번 주 중)
- 베타 = 톡방 공지 + 검색 노출은 계속 차단? / 검색 노출까지 해제?
- 의견 수집 창구: 사이트 "의견 보내기"(VOC) 하나로 모을지, 톡방도 병행할지
- 정식 오픈 기준: 무엇이 확인되면 "정식"인가 (예: 2주간 큰 오류 없음, 파일 등록 안정)
**오픈 시 할 일**(안재찬): noindex 해제 + 서치콘솔 삭제요청 취소, 톡방 공지문

### C. 담당 나눔
가이드 17번 표 여섯 영역: 등록요청 검수 / 자료 관리·정리 / 의견(VOC) 답변 / 카테고리·태그 정리 / 대시보드·지표 확인 / 새 자료 발굴·수집
**팁**: 사람별이 아니라 "주 담당 1 + 백업 1"로. 검수는 A안 결과에 따라 부담이 달라지니 A 뒤에 정한다.
**기록**: 정해지면 가이드 17번 표에 반영(안재찬).
