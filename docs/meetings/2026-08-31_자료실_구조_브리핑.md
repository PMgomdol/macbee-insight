## 자료가 올라가는 흐름
1. 제안 — 누구나 자료 등록 폼(URL 또는 파일 10MB). 제출 시 중복 자동 확인
2. 대기 — 등록요청에 쌓임, 운영진에게 메일. 승인 전 제목·설명·분류·태그 다듬기 가능
3. 승인 — 서로 다른 운영진 2명. 관리자는 사유를 적고 단독 승인 가능(예외)
4. 게시 — 사이트 공개, 제안자에게 메일. 파일 자료는 이 시점에 드라이브로 이동

원칙은 2인 승인. 관리 화면에 "자료 추가" 버튼은 없고 운영진도 같은 폼으로 제안한다.

## 파일은 맥비님 드라이브에 (연결 진행 중)
| | |
|---|---|
| 저장 시점 | 승인 순간 자동 이동. 대기 중엔 사이트 임시 저장소, 반려 파일은 제외 |
| 파일명 | 운영진이 정리한 제목 |
| 공유 범위 | 파일별 "링크가 있는 사람은 보기". 스크립트는 자기가 만든 폴더 밖 접근 불가 |
| 실패 시 | 운영진 메일, 임시 링크로 계속 다운로드, 자료 관리 "드라이브로"로 재시도 |
| 왜 이 방식 | 개인 드라이브엔 봇이 저장 불가 → 맥비님 계정에서 실행되는 스크립트가 받아 저장. 맥비님 1회 설정, 이후 수정은 운영 쪽 |
| 남은 일 | 맥비님 설정 → 연결 테스트 → 기존 20건 이관 |
