## 자료가 올라가는 흐름
1. 제안 — 누구나 자료 등록 폼(URL 또는 파일 30MB). 제출 시 중복 자동 확인
2. 대기 — 등록요청에 쌓임, 운영진에게 메일. 승인 전 제목·설명·분류·태그 다듬기 가능
3. 승인 — 서로 다른 운영진 2명. 관리자는 사유를 적고 단독 승인 가능(예외)
4. 게시 — 사이트 공개, 제안자에게 메일. 파일 자료는 이 시점에 드라이브로 이동

원칙은 2인 승인. 관리 화면에 "자료 추가" 버튼은 없고 운영진도 같은 폼으로 제안한다.
(이 원칙을 누구에게 적용할지가 오늘 안건 1)
