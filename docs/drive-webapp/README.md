# 드라이브 저장 웹앱 — 운영 메모 (내부용)

구조: 맥비님 계정 껍데기(`shell/`) → 개발 모드 라이브러리(`library/`, asa067714 소유) → 맥비님 드라이브.
실행 주체 = 껍데기 배포자(맥비님). 라이브러리 저장 즉시 반영되므로 수정은 복사본에서 먼저 테스트.

라이브러리: https://script.google.com/d/1bJq2z-iH2JyleL0WNhoSL2KgK0h88FQIw5zcurLQku3kL8-HdqO-U7Q1/edit
- 배포는 `library/`에서 `npx @google/clasp push -f` (버전 생성 불필요, 개발 모드)
- 스크립트 속성 `DRIVE_SECRET` 은 라이브러리 편집기 → 프로젝트 설정 → 스크립트 속성에서 직접 입력. 코드에 넣지 않음(레포 공개)
- 맥비님이 개발 모드로 쓰려면 맥비님 계정을 라이브러리 편집자로 공유해야 함 (안내문 보내기 전에)

맥비님께 보내는 것: `맥비님_배포_안내.md`, `shell/Code.gs`, `shell/appsscript.json`

연결 후 확인: 웹앱 URL로 `{"action":"ping","secret":…}` POST → `{ok:true, folder:…}`

결정 사항 (2026-08-30)
- 전송 시점 = 승인 시점. 반려 파일은 드라이브에 안 감. 파일명 = 정리된 제목.확장자 (서버가 만들어 보냄)
- 이중 저장 없음. 드라이브 저장 성공 후 Supabase 임시 파일 삭제. 실패 시 Supabase 링크 유지 + 운영진 알림
- 트레이드오프: 맥비님 계정에 문제가 생기면 원본은 드라이브에만 있음 (맥비님 자료실이므로 맥비님 소유가 원본)
