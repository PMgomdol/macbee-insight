# 맥비 자료실 — 드라이브 저장 연결 안내

자료실에 올라오는 파일을 맥비님 드라이브에 자동 저장하려고 합니다.
한 번만 설정하면 이후에는 손댈 일이 없고, 코드 수정은 제가 제 쪽에서 합니다.
새로 가입하거나 결제할 것은 없습니다. 10분 정도 걸립니다.

저장 방식: 맥비님 드라이브에 "맥비기획 자료실 (자료실 업로드)" 폴더가 자동으로 생기고, 자료실 파일이 그 안에 들어갑니다.
이 연결은 그 폴더 안의 파일만 다룰 수 있고, 맥비님 드라이브의 다른 파일에는 접근하지 못합니다.
그래서 먼저 보내주신 폴더는 쓰지 않아도 됩니다.

---

## 0. 보내주신 폴더 공유 설정 확인

"맥비기획 자료실" 폴더가 지금 "링크가 있는 모든 사용자 → 편집자"로 되어 있어요.
링크를 아는 사람은 누구나 파일을 올리고 지울 수 있는 상태인데, 의도하신 건지 여쭤봅니다.
이 연결에는 폴더 공유가 필요 없어서, 따로 쓰실 일이 없으면 "제한됨"으로 바꿔두셔도 됩니다.
(드라이브에서 폴더 우클릭 → 공유 → 일반 액세스 → 제한됨)

## 1. 스크립트 만들기

1. https://script.google.com 접속 (맥비님 구글 계정으로 로그인)
2. 왼쪽 위 "새 프로젝트"
3. 상단 제목 "제목 없는 프로젝트"를 눌러 `맥비자료실 드라이브저장` 으로 변경

## 2. 파일 두 개 붙여넣기

먼저 설정 파일을 보이게 합니다.

1. 왼쪽 메뉴 톱니바퀴 "프로젝트 설정"
2. "appsscript.json 매니페스트 파일을 편집기에 표시" 체크
3. 왼쪽 메뉴 "편집기"로 돌아오기

이제 파일 두 개를 바꿔 넣습니다.

1. `appsscript.json` 클릭 → 내용 전부 지우고 → 보내드린 `appsscript.json` 내용 붙여넣기 → 저장
2. `Code.gs` 클릭 → 내용 전부 지우고 → 보내드린 `Code.gs` 내용(4줄) 붙여넣기 → 저장

저장 뒤 왼쪽 "라이브러리" 아래에 `MacbeDrive` 가 보이면 됩니다.

## 3. 드라이브 권한 승인 (한 번)

1. 상단 함수 선택 드롭다운에서 `testDriveWebapp` 선택
2. "실행" 클릭
3. "승인 필요" 창 → 권한 검토 → 맥비님 계정 선택
4. "Google에서 확인하지 않은 앱" 화면이 나오면 → 고급 → "맥비자료실 드라이브저장(으)로 이동" 클릭
   (맥비님이 직접 만든 스크립트라서 나오는 안내입니다)
5. 허용
6. 아래 실행 로그에 `폴더 준비됨: 맥비기획 자료실 (자료실 업로드)` 가 나오면 성공입니다.
   드라이브에 가보시면 그 이름의 폴더가 새로 생겨 있습니다.

## 4. 웹 앱으로 배포

1. 오른쪽 위 "배포" → "새 배포"
2. 왼쪽 톱니바퀴 "유형 선택" → 웹 앱
3. 설정
   - 설명: `자료실 드라이브 저장`
   - 다음 사용자 인증 정보로 실행: 나 (맥비님 이메일)
   - 액세스 권한이 있는 사용자: 모든 사용자
4. "배포" 클릭 (권한 창이 나오면 3번과 같이 허용)
5. 화면에 나오는 웹 앱 URL (`https://script.google.com/macros/s/…/exec`) 을 복사해서 저에게 보내주세요.

"모든 사용자"로 여는 것은 자료실 서버가 이 주소를 부를 수 있게 하기 위한 것입니다.
비밀 키가 맞아야만 동작하기 때문에 주소를 알아도 다른 사람은 쓸 수 없습니다.

## 5. 저를 편집자로 추가

문제가 생겼을 때 제가 들여다볼 수 있게 하려는 것입니다.

1. 스크립트 편집기 오른쪽 위 사람 모양 "공유" 아이콘
2. `asa067714@gmail.com` 입력 → 편집자 → 보내기

## 저에게 보내주실 것

- 4번의 웹 앱 URL
- 0번 폴더 공유는 어떻게 하실지 한마디

받으면 제가 비밀 키를 연결하고 테스트 파일을 하나 올려서 새 폴더에 들어가는지 확인해 드리겠습니다.

## 참고

- 파일은 맥비님 소유, 맥비님 드라이브 용량으로 저장됩니다.
- 이후 기능 수정은 제 쪽 코드에서 하고, 맥비님이 다시 배포하실 일은 없습니다.
- 비밀번호를 바꾸시거나 권한을 취소하시면 연결이 끊길 수 있습니다. 그때는 3번(승인)만 다시 하시면 됩니다. 끊긴 동안에도 자료실은 예전 방식으로 저장하니 등록이 멈추지는 않습니다.
