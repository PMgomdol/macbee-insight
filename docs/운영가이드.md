## 1. 한눈에 보는 구조

```
방문자 ──→ 웹사이트 (Next.js / Vercel 자동배포)
              │ 읽기: Supabase (archive_item · faq)
              │
자료 제안 ──→ staging_proposal → 운영진 승인 → archive_item
              │                      │
              │  (메일: 운영진에게)    │  (메일: 제안자에게)
              ▼                      ▼
        Apps Script MailApp 발송 (Gmail)

원본(SSOT) = 구글 시트 「자료 DB」 · 사이트 DB = Supabase
둘은 수동/스크립트 동기화 — 시트 고치면 Supabase도 같이 고쳐야 사이트에 반영됨
```

- **콘텐츠 3종**: 양식·템플릿(파일) / 콘텐츠(아티클·영상·가이드) / 실무 Q&A(FAQ)

- **배포**: `main` 브랜치 push → Vercel 자동 배포 (1~2분). 사이트 캐시 1시간

## 5. 일상 운영 루틴

### 제안 처리 (메일 받으면)
1. 메일의 링크로 관리자 페이지 진입
2. 내용 확인 — 링크 열리는지, 중복 아닌지(등록 시 자동 중복검사 있음), 자료실 성격에 맞는지
3. 승인 또는 반려(사유 작성) → 제안자에게 자동 메일
4. 승인분은 Supabase에 바로 게시됨. **시트에도 추가해야 SSOT 유지** (주기적으로 동기화)

### 자료 수정
- 시트에서 고침 → Supabase도 같이 고침 (필드: title·summary·tags·category·url·published_at·format·status)
- 사이트 반영은 캐시 때문에 최대 1시간

### 자료 삭제 — 반드시 이 절차 (⚠️ 과거 삭제분 부활 사고 2회)
1. Supabase 원본 JSON 백업
2. **「삭제 시트 모음」 탭에 이관** — 사유·제거일 기록 (재유입 방지 대조용)
3. 자료 DB 시트에서 행 삭제
4. Supabase에서 삭제
- **대량 임포트 시 삭제 시트의 URL과 대조 필수** — 지웠던 자료가 되살아나는 사고 방지
- 마킹만 하면 자동 삭제 안 됨. 실행까지 해야 삭제

### 모니터링 (주 1회 권장)
- PostHog: 방문·인기 자료·**결과 0건 검색어** (`scripts/zero_search_report.py`) → 동의어 보강·수집 우선순위
- 링크 생존: 스크립트로 일괄 체크 가능 — 단 **SSL 오류는 사망 아님, 브라우저 확인 후 판단**

## 6. 콘텐츠 규칙 (검수 기준 요약)

- **보조설명**: 한글 1문장 40~120자 "~입니다"체. 실제 본문 근거. 금지: 영문 문장·메타 복붙·홍보 문구·잘린 문장·깨진 글자
- **태그**: 4~6개, 한글 위주, 기존 태그 어휘 재사용 우선
- **자료 형식**: 아티클 / 가이드(정형화된 목차의 전자책형) / 템플릿(실제 양식) / 영상 / 홈페이지(도구·포털) / 강의 / 기획서
- **메뉴 구분(양식·템플릿 vs 콘텐츠)**: **받아서 쓰는 자료면 양식·템플릿, 읽거나 보는 자료면 콘텐츠** (2026-09-01 확정). 완성 샘플·예시 문서, 실무용 목록, 디자인 에셋도 "쓰는 것". 등록 시 AI가 내용을 읽고 자동 판정하고, 내용을 못 읽은 파일은 양식·템플릿이 기본 — 검수·자료 관리에서 변경 가능
- **링크**: 단축링크(bit.ly 등) 금지 — 원본 URL로. 구글 리다이렉트 래퍼도 풀어서
- **발행일**: YYYY-MM-DD 형식 통일

## 7. 배포·인프라 소소한 것

- 코드 수정 → `main` push → 자동 배포. 환경변수 바꾸면 **Redeploy 필수**
- 환경변수는 **pmgomdol 계정 Vercel**에서만 유효 (openpath 계정의 동명 프로젝트는 가짜)
- Gemini API(자료 자동분류)는 무료 쿼터 — 소진 시 `gemini-2.5-flash-lite`가 별도 버킷이라 살아있을 수 있음
- 사고 기록 (재발 방지):
  - 삭제분 부활 2회 → 삭제 시트 대조 절차 신설
  - PostHog 수집 중단 6일 (잘못된 env가 빌드에 인라인) → 수집 주소 코드 고정으로 해결

## 8. 자주 묻는 것 (운영진 FAQ)

**Q. 사이트에 자료가 안 보여요** — 캐시 1시간 대기 → Supabase `status='public'` 확인 → 그래도 안 나오면 재배포

**Q. 제안 메일이 안 와요** — §3 점검 순서. 쿼터(100통/일) 초과 여부도

**Q. 실수로 자료를 지웠어요** — 삭제 시트에 원본 있음. 행 복사해서 자료 DB로 되돌리고 Supabase에 INSERT

**Q. 검색이 이상해요** — 오타·초성(ㅍㄱㅁ) 검색은 정확 일치가 0건일 때만 발동하는 정상 동작. "비슷한 자료를 보여드려요" 안내가 뜸
