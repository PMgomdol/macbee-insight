### 운영 구조
| 자원 | 상태 |
|---|---|
| 호스팅 | Vercel (자동 배포, main 브랜치) |

### 데이터 흐름
```
[멤버 등록]
  카톡방 → /submit → URL/파일 입력
  → AI 분석 (제목·요약·카테고리·태그·형식 자동 추출)
  → staging_proposal 저장 (검토 대기)

[운영진 검토]
  /admin → 운영진 2명 승인 → archive_item 자동 이관
  (운영진 2명 미확보 시 admin 단독 승인 폴백)

[멤버 열람]
  홈 → 검색·필터·카테고리 칩 → 카드 클릭 → 외부 링크/파일 다운로드
```

## 2. 페이지 구성

| 경로 | 용도 | 핵심 기능 |
|---|---|---|
| `/` | 홈 | Hero 검색 + 인기 TOP 10 + 전체 자료 필터 |
| `/files` | 양식·템플릿 | 다운로드 가능 파일 자료 |
| `/insights` | 아티클·영상 | 외부 큐레이션 콘텐츠 |
| `/faq` | FAQ | 70건 + 카테고리 점프 + 검색 |
| `/search` | 검색 | 자동완성 + 동의어 사전 + 필터 |
| `/submit` | 자료 등록 | URL/파일 등록 + AI 자동 분류 |
| `/admin` | 운영진 검토 | 승인·반려 (운영진 전용) |
| `/login` | 로그인 | Google OAuth |

### 검색 UX (특화)
- **자동완성** — 입력 시 제목·태그·카테고리 매칭, 200ms debounce
- **동의어 사전** 60+ 매핑 — 예: "화면설계서" → 기획서·와이어프레임·스토리보드
- **최근 검색** localStorage 6개 자동 저장
- **추천 키워드** — 빈 검색창에 트렌딩 노출
- **관련도 정렬** — 원본 매칭 가중치 10, 동의어 5, 제목 hit +5

### 디자인 시스템
**Microsoft Fluent 2** — accent 1색 (#0f6cbd) + 중성 그레이, Lucide 아이콘, 이모지 미사용, 다크모드 수동 토글 3-mode (시스템·라이트·다크).
