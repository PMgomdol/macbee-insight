1시작하기

접속과 로그인

관리자 화면은 운영진만 볼 수 있어요. 구글 계정으로 로그인하고, 그 계정이 운영진으로 승인돼 있어야 들어갈 수 있어요.

  1. 주소창에 macbe-archive.com/admin-mb26 입력 — 사이트 하단 "운영/관리" 링크로도 들어올 수 있어요(운영진에게만 보여요).
  2. Google로 계속하기를 눌러 로그인
  3. 운영진으로 승인된 계정이면 관리 홈으로 바로 이동해요.
안 열려요? 로그인은 됐는데 "아직 운영진이 아니에요"가 뜨면, 다른 운영진(관리자)이 승인해 줘야 해요. → 운영진 초대·승인 참고.
2둘러보기

화면 한눈에

왼쪽 메뉴(LNB)로 모든 기능을 오가요. 로그인하면 처음 보이는 홈에는 지금 처리해야 할 일이 건수로 모여 있어요 — 빨간 숫자를 눌러 바로 이동하면 돼요.

메뉴 6가지

  • 홈 — 지금 처리할 일(자료요청·미처리 의견·운영진 신청) 건수와 바로가기
  • 대시보드 — 방문·조회 등 사이트 지표(PostHog)
  • 자료등록요청 — 멤버가 제안한 자료를 승인/거절
  • VOC — 사용자가 [의견 보내기]로 남긴 의견 관리·답변
  • 백로그 — 운영진끼리 함께 관리하는 작업 보드
  • 운영진 초대 — 새 운영진 초대·신청 승인
3가장 자주 하는 일

자료 등록요청 처리

멤버가 사이트에서 제안한 자료가 여기 모여요. 운영진 2명이 승인하면 자동으로 자료실에 올라가고, 부적절하면 거절해요.

1내용 확인 — 제목·분류·링크를 열어보고 자료실에 맞는지 판단해요. 2승인 — 맞으면 [승인]. 서로 다른 운영진 2명이 승인하면 자동으로 자료실에 게시돼요. 3거절 — 부적절하면 [거절], 사유를 적으면 제안자에게 메일로 전달돼요.
단독 승인 운영진이 2명 미만이라 2인 승인이 어려울 땐, 관리자가 사유를 적고 단독 승인할 수 있어요(기록에 남아요). 평소엔 2인 승인이 원칙이에요.
기준이 궁금할 때 어디로 분류하지? 언제 거절하지? 싶으면 → 8. 운영 기준·참고에 정리해뒀어요.
4사용자 목소리

의견(VOC) 관리

사용자가 [의견 보내기]로 남긴 제안·오류·문의·칭찬이 여기 모여요. 칸반 보드에서 상태를 옮기고, 담당자를 정하고, 이메일을 남긴 사람에겐 답장할 수 있어요.

1카드를 옮겨 상태 변경 — PC에선 카드를 다른 칸으로 끌어다 놓고, 휴대폰에선 카드를 눌러 뜨는 창에서 상태를 바꿔요. 2담당자·우선순위 지정 — 카드를 열어 담당자를 정하면, 누가 맡았는지 서로 알 수 있어요. 3답장 — 이메일을 남긴 사람이면 [메일로 답장 보내기]로 내 메일앱이 열려요(실제 발송은 개인 메일에서). 이메일이 없으면 처리 메모에 기록만 남겨요.

상태의 뜻

  • 신규 — 방금 들어와 아직 아무도 안 본 의견
  • 처리중 — 담당자가 보고 있는 중
  • 보류 — 지금은 미루는 것
  • 답변완료 — 답장은 보냈고, 상대 반응을 지켜보는 단계(아직 열려 있음)
  • 종료 — 완전히 끝난 것. 최근 2주만 보이고 지난 건 [더 보기]로 접혀요.
5함께 일하기

백로그 보드

운영진끼리 함께 관리하는 작업 보드예요. "이 자료 다시 분류하자", "이 기능 개선하자" 같은 할 일을 적어두고, 나눠 맡고, 끝내가요. 혼자 머릿속에 담아두는 대신 같이 기록해요.

1추가 — 맨 위 칸에 할 일을 적고 분류·담당자·우선순위를 골라 [추가]. 엔터로도 돼요. 2진행 — 할 일 → 진행중 → 완료로 카드를 옮겨요(VOC와 같은 방식). 3완료 정리 — 완료 칸은 최근 2주만 보이고, 지난 건 [더 보기]로 접혀 화면이 깔끔해요.
VOC와 뭐가 달라요? VOC는 사용자가 보낸 의견, 백로그는 운영진이 스스로 정하는 할 일이에요. 서로 다른 보드예요.
6팀 늘리기

운영진 초대

새 운영진을 들이는 방법과, 신청한 사람을 승인하는 방법이 한 곳에 있어요.

초대하기

  1. 운영진 초대 메뉴에서 초대할 사람의 이메일을 입력해요.
  2. [초대 메일 보내기]를 누르면 초대 링크가 담긴 메일이 내 메일앱에 열려요 — 확인하고 보내면 돼요.
  3. 상대가 링크로 들어와 구글 로그인 + 운영진 신청을 해요.
  4. 신청이 들어오면 이 화면 아래 신청 목록에 떠요 — [승인]하면 그때부터 운영진이에요.
본인 신청은 본인이 승인 못 해요 안전을 위해, 신청한 사람과 다른 운영진이 승인해야 해요. 그래서 초기엔 최소 2명이 필요해요.
7알아두면 편해요

알림 메일 · 자주 묻는 것

이런 일이 생기면 메일이 와요

  • 새 자료 제안이 들어오면 → 운영진 전원에게 (바로 검토 링크 포함)
  • 새 의견이 들어오면 → 운영진 전원에게 (종류·내용·처리 링크 포함)
  • 제안을 승인/거절하면 → 제안한 사람에게 결과 안내
메일은 알림용 메일이 오면 관리자 화면에서 처리하면 돼요. 알림 수신은 운영진 계정으로 자동 관리돼요.

자주 묻는 것

  • 휴대폰에서도 되나요? — 네. 카드를 끌어놓는 대신 눌러서 상태를 바꾸면 돼요. 메뉴는 위쪽에 접혀 나와요.
  • 실수로 카드를 잘못 옮겼어요. — 다시 원래 칸으로 옮기면 돼요. 삭제가 아니라 상태만 바뀌는 거예요.
  • 종료·완료한 게 안 보여요. — 최근 2주만 펼쳐 보여요. 칸 아래 [지난 N건 더 보기]를 누르면 전부 나와요.
  • 로그아웃은 어디서? — PC는 우측 상단, 휴대폰은 메뉴 하단에 있어요.
막히면 화면이 안 뜨거나, 잘못 지운 것 같거나, 판단이 어려운 게 있으면 안재찬에게 알려주세요 — asa067714@gmail.com. 원본 자료 수정·삭제도 여기로요.
8운영 기준·참고

분류·등록·역할 기준

매일 쓰는 화면 밖의 "이건 어떻게 하지?"를 모아뒀어요. 승인·거절할 때, 자료를 올리거나 고칠 때 기준으로 삼으세요.

어디로 분류하죠? — 콘텐츠 vs 양식·템플릿

  • 양식·템플릿 — 받아서 채워 쓰는 것. 편집 가능한 파일(구글 문서·시트·슬라이드, PPT·엑셀·워드·한글), 다운로드해 수정하는 템플릿.
  • 콘텐츠 — 읽고 배우는 것. 가이드·아티클·영상·강의자료·피그마·커뮤니티 글 등.
헷갈리면 "채워 쓰는 거면 양식·템플릿, 보고 배우는 거면 콘텐츠." 한 자료가 둘 다여도 주된 쓰임으로 정하면 돼요.

자료를 직접 올리거나 고치려면

  • 새 자료 올리기 — 운영진도 멤버와 똑같이 [자료 제안](/submit)으로 올려요. 그러면 자료등록요청에 떠서 2인 승인으로 게시돼요. (바로 추가하는 버튼은 일부러 두지 않았어요 — 검토 흐름을 하나로 두려고.)
  • 수정·삭제 — 이미 올라간 자료의 제목·링크 고치기, 깨진 링크 교체, 자료 내리기는 지금 화면에 버튼이 없어요. 백로그에 적어두거나 관리자(안재찬)에게 요청하면 원본에서 처리해요.

언제 거절하죠?

  • 중복 — 같은 자료가 이미 자료실에 있음
  • 주제 밖 — 기획자 커뮤니티와 관계가 옅음
  • 링크 문제 — 열리지 않거나 접근 권한이 없음
  • 유효하지 않음 — 너무 오래되어 지금은 맞지 않음
  • 저작권·개인정보 소지 — 판단이 애매하면 거절 대신 보류하고 운영진끼리 상의
거절할 땐 사유를 적으면 제안한 사람에게 메일로 전달돼요. 짧아도 이유가 있으면 다음 제안이 더 좋아져요.

운영진과 관리자는 뭐가 다르죠?

관리자

현재 관리자는 안재찬이에요. 원본을 손대는 일(수정·삭제)이나 단독 승인은 관리자를 거쳐요.

대시보드는 뭘 보죠?

방문·조회 지표(PostHog)예요. 매일 볼 필요는 없고, 주·월 단위로 훑어보는 참고용이에요.

  • 방문자 추이 — 사람이 늘고 있는지
  • 인기 자료·검색어 — 뭘 많이 찾는지 → 어떤 자료를 더 채우면 좋을지 힌트
  • 유입 경로 — 어디서 들어오는지
활용 "검색은 많은데 결과가 없는 키워드"가 보이면, 그 주제 자료를 백로그에 적어 채워가면 돼요.
